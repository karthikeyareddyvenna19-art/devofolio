## Description

This is my responsive personal portfolio website created using HTML and CSS.

The portfolio includes:

- About Me section
- Projects section
- Responsive project cards
- Responsive navigation
- Contact links
- CSS Flexbox
- CSS Grid
- Mobile-first responsive design

## Technologies Used

- HTML5
- CSS3
- Flexbox
- CSS Grid
- Media Queries

## Run Locally

1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in a web browser.

No additional installation is required.

## Live Website

https://yourusername.github.io/portfolio/

Replace `yourusername` with your GitHub username after deploying the project.

## GitHub Pages Deployment

1. Create a repository on GitHub.
2. Upload `index.html`, `style.css`, and `README.md`.
3. Open the repository's **Settings**.
4. Select **Pages**.
5. Under **Build and deployment**, select:
   - Source: Deploy from a branch
   - Branch: `main`
   - Folder: `/ (root)`
6. Click **Save**.
7. GitHub will provide the public website URL.
